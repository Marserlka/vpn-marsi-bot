# ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ТЗ)
## Разработка Telegram-бота для автоматической продажи VPN-подписок с интеграцией панели Marzban, жёстким лимитом устройств и маркетинговыми инструментами

---

## 1. ОБЩЕЕ ОПИСАНИЕ СИСТЕМЫ

Система представляет собой коммерческий **Telegram-бот** (витрина и личный кабинет) для автоматизации продаж индивидуального VPN-доступа. Бот выступает посредником между пользователем, платёжной системой и панелью управления VPN **Marzban**, развёрнутой на сервере с ОС **Aurorix** (Нидерланды, 1-2 ядра, 2-4 ГБ RAM).

### Ключевая концепция
* **Бизнес-модель:** 1 подписка = 1 устройство. Стоимость — **30 рублей / месяц** (тарифы: 1 мес — 30 руб, 3 мес — 90 руб, 6 мес — 180 руб).
* **Защита от шеринга (главная фича):** жёсткое пресечение одновременных сессий по одному ключу средствами панели Marzban. При обнаружении параллельного использования ключ временно блокируется.
* **Протоколы обхода блокировок:** **VLESS-Reality** (маскировка под легальные, разрешённые регулятором домены) и **AmneziaWG** как запасной протокол.
* **Клиентский софт:** подключение через сторонние конфигураторы (Amnezia, FoXray, v2rayNG, NekoBox) по универсальным sub-ссылкам.
* **Маркетинговый контур:** промокоды, реферальная программа, внутренний баланс с ручным пополнением админом — всё это должно повышать конверсию и удержание при чеке 30 руб/мес, где продажи возможны только в полностью автоматическом режиме.

---

## 2. АРХИТЕКТУРА И ТЕХНИЧЕСКИЙ СТЕК

* **Серверная ОС:** Aurorix (Linux, 1-2 ядра, 2-4 ГБ RAM), Нидерланды.
* **Ядро VPN:** Xray / панель управления **Marzban** (установка через Docker).
* **Стек разработки бота:** Python (**aiogram 3.x**).
* **База данных:** SQLite на старте, с возможностью миграции на PostgreSQL.
* **Планировщик (cron-задачи):** APScheduler или системный cron для уведомлений и проверки истечения подписок.
* **Платёжные шлюзы:**
  * **MVP (первый релиз):** реализовать модуль оплаты как абстрактный интерфейс (`PaymentProvider`) с одной рабочей заглушкой/тестовым провайдером, чтобы бизнес-логика (активация подписки после оплаты) была полностью готова и протестирована.
  * **Второй этап (боевая интеграция):** **AuraPay**, **Platega**, **CryptoBot Pay**, **Telegram Stars** — подключаются по очереди без изменения основной логики бота (только реализация конкретного класса-провайдера).
* **Взаимодействие Бот ↔️ Marzban:** через официальный **Marzban REST API**.

## 3. МЕХАНИКА И БИЗНЕС-ЛОГИКА СИСТЕМЫ

### 3.1. Механика ограничения «1 ключ = 1 устройство»

Реализуется строго через встроенный функционал **Marzban**:
1. При создании пользователя через API бот передаёт параметр лимита IP со значением `1` (`"ips_limit": 1`).
2. Marzban непрерывно анализирует логи подключений Xray.
3. **Логика смены сети (ОК):** если пользователь переключается с домашнего Wi-Fi на мобильный интернет (IP меняется), старая сессия закрывается, новая открывается — блокировки **нет**.
4. **Логика коллизии сессий (бан):** если по одному ключу фиксируется **одновременный параллельный трафик** с разных устройств (даже за одним роутером), Marzban мгновенно сбрасывает сессии и временно блокирует ключ (~5 минут), выдавая ошибку соединения на обоих устройствах.

### 3.2. Механика «обхода белых списков» (маскировка трафика)

* На стороне Marzban в настройках входящего соединения **VLESS-Reality** настраивается маскировка (**SNI / Dest**) под легальный зарубежный домен с TLS 1.3.
* **Важная поправка по итогам боевого теста (02.09.2026):** первоначальная идея маскироваться под российские домены (vk.com, kinopoisk.ru, max.com) для сервера, физически расположенного **за границей** (Нидерланды), не работает и даже вредит — российский ТСПУ сопоставляет SNI из TLS-пакета с реальным диапазоном IP этого домена, и коллизия «SNI=vk.com, IP=Нидерланды» приводит к обрыву соединения. Проверено на практике: два независимых клиента из России не могли выйти в интернет именно по этой причине, хотя сам прокси на сервере работал корректно (подтверждено локальным тестовым VLESS-клиентом на сервере).
* **Рабочее решение:** маска берётся с крупного зарубежного сайта на глобальном CDN, чьи IP-адреса легитимно встречаются в разных странах (в т.ч. в Европе) — например **addons.mozilla.org** (используется сейчас в проде), либо www.microsoft.com, dl.google.com, discord.com. Требования к домену-маске остаются прежними: TLS 1.3, HTTP/2, стабильная доступность.
* Бот генерирует для пользователя единую подписочную (sub) ссылку, которую Marzban отдаёт в формате, совместимом с Amnezia, FoXray, v2rayNG, NekoBox.
* **AmneziaWG** используется как запасной протокол на случай сбоев VLESS-Reality — за счёт обфускации пакетов (junk-байты) трафик выглядит как «белый шум», а не как VPN.

## 4. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ К TELEGRAM-БОТУ

### 4.1. Клиентская часть (интерфейс пользователя)

После команды `/start` пользователь видит главное меню (inline-кнопки):

1. **💰 Купить / Продлить VPN**
   * Выбор периода подписки (1 мес — 30 руб, 3 мес — 90 руб, 6 мес — 180 руб).
   * Поле ввода **промокода** — при валидном промокоде цена пересчитывается на лету (скидка в % или в фиксированной сумме).
   * Выбор способа оплаты: внутренний баланс бота, либо один из платёжных провайдеров (на MVP — заглушка, далее AuraPay / Platega / CryptoBot / Stars).
   * Вызов API платёжной системы ➡️ генерация уникальной инвойс-ссылки.
   * Ожидание вебхука от платёжки. После успешной оплаты — активация/продление подписки и создание/обновление клиента в Marzban.

2. **👤 Личный кабинет**
   * Статус подписки: `Активна` / `Истекла`, дата окончания (`ДД.ММ.ГГГГ`).
   * Текущий внутренний баланс пользователя (руб.).
   * Кнопка получения ключа: бот выдаёт sub-ссылку для импорта в Amnezia / FoXray / v2rayNG / NekoBox.
   * Предупреждение: *«Внимание! 1 подписка предназначена только для 1 устройства. При одновременном включении на двух устройствах доступ автоматически блокируется.»*

3. **👥 Реферальная система**
   * Персональная реферальная ссылка (深linking через `/start ref_<id>`).
   * Условие начисления: бонус (X дней подписки или X рублей на внутренний баланс — задаётся админом в настройках) начисляется пригласившему **после первой успешной оплаты** приглашённого.
   * Раздел статистики: количество приглашённых, количество оплативших, сумма/дни заработанных бонусов.

4. **📥 Инструкция по настройке**
   * Пошаговые текстовые/видео гайды по установке приложений на iOS, Android, Windows и импорту sub-ссылки.

5. **🆘 Поддержка**
   * Кнопка-ссылка на аккаунт администратора.

### 4.2. Автоматическая работа с подписками (cron-задачи)

* **За 3 дня до окончания подписки:** уведомление — *«Ваша VPN-подписка истекает через 3 дня. Рекомендуем продлить её заранее, чтобы не остаться без связи.»*
* **За 1 день до окончания подписки:** уведомление — *«Внимание! Подписка истекает завтра. Нажмите “Продлить”, чтобы сохранить доступ.»*
* **В момент окончания подписки:** если оплата не поступила — бот делает API-запрос к Marzban на деактивацию/удаление пользователя (ключ перестаёт работать) и уведомляет: *«Ваша подписка истекла. Доступ к VPN ограничен.»*
* **При повторной оплате:** бот через API активирует/пересоздаёт пользователя в Marzban.

### 4.3. Административная панель (команда `/admin`)

Доступ открывается **отдельной командой `/admin`** (не через общее меню) строго после проверки Telegram ID администратора из списка в `.env` / конфиге.

Функции:

* **📊 Статистика:** общее число пользователей, число активных платных подписок, оборот средств (за день/месяц), число использованных промокодов, статистика по рефералам.
* **👤 Управление пользователями:**
  * Поиск по Telegram ID или @username.
  * Ручное продление подписки, ручное отключение (деактивация в боте и в Marzban).
  * **Пополнение внутреннего баланса пользователю вручную** (для компенсаций, конкурсов, спорных ситуаций) — с логированием, кто и когда начислил.
  * Просмотр выданного пользователю ключа/sub-ссылки.
* **🎟 Управление промокодами:**
  * Создание промокода (например, `START2026`).
  * Параметры: размер скидки (% или фиксированная сумма в рублях), лимит количества активаций, срок действия (дата).
  * Просмотр списка активных/истёкших промокодов и статистики использования.
* **📢 Массовая рассылка:** отправка текстового сообщения (опционально с изображением) всей базе пользователей — используется в том числе при форс-мажорных сменах IP сервера или блокировках.

## 5. ТРЕБОВАНИЯ К НАДЁЖНОСТИ И БЕЗОПАСНОСТИ

* **Токены и пароли:** все API-ключи платёжных систем, пароль от Marzban API и токен бота хранятся строго в файле окружения `.env`. Выгрузка их в открытый Git-репозиторий запрещена.
* **Логирование:** ведение лога ошибок (`errors.log`). Ошибки недоступности Marzban API или сбои платёжки не должны «ронять» скрипт бота — все внешние вызовы оборачиваются в try/except с ретраями и понятным сообщением пользователю.
* **База данных:** обязательное создание резервных копий БД раз в сутки (например, cron-job с копированием файла SQLite / `pg_dump`).
* **Разграничение доступа:** админ-функционал (`/admin`) доступен только ID из белого списка администраторов; попытки доступа посторонних логируются.

## 6. КРИТЕРИИ ПРИЁМКИ РАБОТЫ (ЧЕК-ЛИСТ ДЛЯ ТЕСТА)

1. [ ] Бот успешно генерирует платёжную ссылку/инвойс на 30 рублей (через тестовый провайдер на MVP).
2. [ ] После оплаты бот регистрирует/продлевает пользователя в панели Marzban и выдаёт рабочую sub-ссылку.
3. [ ] Выданный ключ успешно импортируется в конфигуратор (Amnezia / v2rayNG / FoXray) и даёт доступ к интернету через маскировку под vk.com / max.com / kinopoisk.ru.
4. [ ] **Тест лимита устройств:** при попытке включить один и тот же ключ на двух устройствах одновременно Marzban прерывает сессию на обоих устройствах в течение 1–2 минут.
5. [ ] При ручном отключении подписки админом или по истечении срока доступ в интернет у пользователя прекращается.
6. [ ] Промокод корректно уменьшает стоимость подписки при оформлении покупки и учитывает лимит активаций и срок действия.
7. [ ] Реферальная ссылка генерируется корректно; после первой оплаты приглашённого пригласившему начисляется настроенный бонус (дни/рубли), отображается в статистике.
8. [ ] Команда `/admin` открывает панель управления только для ID из списка администраторов; для остальных — недоступна.
9. [ ] Админ может вручную пополнить баланс произвольному пользователю, и это отражается в его личном кабинете.
10. [ ] Уведомления об истечении подписки приходят пользователю ровно за 3 дня и за 1 день до окончания.

## 7. ПРИМЕЧАНИЕ: БЕЗОПАСНОСТЬ ОБЩЕГО IP-АДРЕСА (справочно, не входит в объём работ разработчика)

Все пользователи сервера будут выходить в интернет с **одного общего IP-адреса** (Нидерланды) — это стандартная практика для коммерческих VPN-провайдеров.

* **Для пользователей** — это плюс к анонимности: трафик сотен людей «перемешивается», и по IP невозможно вычислить конкретного пользователя.
* **Для владельца сервиса** — есть риск капчи/блокировок со стороны крупных сайтов (Google и др.), если один из клиентов начнёт злоупотреблять (спам, парсинг, брутфорс). Снижается настройкой на уровне Xray/Marzban: блокировка BitTorrent-трафика и почтовых портов (25, 465, 587).
